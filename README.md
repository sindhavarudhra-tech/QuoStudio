# QuoStudio

QuoStudio is a modern, web-based quotation generator and invoice builder SaaS platform designed for businesses, freelancers, and plant nurseries to seamlessly create, manage, sync, and sign professional documents.

---

## ✨ Features

* **Dynamic Document Editor**: Real-time content editing with native drag-and-drop or click-to-add table row management.
* **Advanced Multi-Page Pagination**: Automatically calculates item limits per page based on project name length, ensuring headers, tables, and footers remain perfectly aligned without layout overflow.
* **Inventory & Database Sync**: Upload custom CSV catalogs and map dynamic columns to instantly sync pricing and item specs directly into quotes.
* **Terms & Conditions Integration**: Toggle and position a fully customizable T&C page anywhere within the document sequence.
* **Client Ecosystem & Workflows**: Search registered users, dispatch quotes across accounts, and review incoming requests or signed agreements.
* **Locked & Secure Sent Quotes**: Drafts feature auto-updating issuance and 20-day validity dates, while sent or accepted quotes lock into read-only files.
* **Digital Signatures**: Built-in support for typing or uploading signature artwork to legally finalize agreements.
* **Responsive Light & Dark Themes**: Fully adaptable UI with a sleek dark mode and high-contrast light mode toggle.
* **Print & PDF Optimization**: Clean print and export stylesheets that strip out navigation panels, toolbars, and drop zones for pristine A4 output.

---

## 🛠️ Tech Stack

* **Backend**: Python (Flask)
* **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5
* **Database / Storage**: PostgreSQL / Custom Relational Schemas
